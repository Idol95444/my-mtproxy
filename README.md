# my-mtproxy

MTProto-прокси для Telegram на базе **telemt** (Rust, client_mss=tspu).  
Обходит российский DPI/ТСПУ 2026. Управление через TUI-меню и Telegram-бот.

## Быстрый деплой

```bash
git clone https://github.com/limbo-wh/my-mtproxy.git
cd my-mtproxy
sudo bash manage.sh
```

После первого запуска команда доступна глобально:
```bash
sudo proxy
```

ОБСЛУЖИВАНИЕ

13) Удалить прокси
14) Проверить связь с Telegram
15) Обновить telemt

## Telegram-бот

Бот управляет прокси прямо из Telegram: статистика, список пользователей, квоты, ссылки, мониторинг памяти.

- Настройка: пункт 19 → установить → задать BOT_TOKEN и CHAT_ID
- Команды: `/start` `/stats` `/users` `/adduser <имя>`
- Алерты: RAM, swap, диск, падение сервиса (не чаще раза в час)

## Требования

- Ubuntu 22.04+ / Debian 12, root
- Домен с A-записью на VPS
- Открытый TCP 443
